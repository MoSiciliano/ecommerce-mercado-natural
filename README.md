## 📌 Descripción del Proyecto

Este proyecto es el frontend interactivo para una tienda en línea de productos orgánicos y frutas. 

Desarrollado completamente en **Vanilla JavaScript** (sin frameworks), demuestra un manejo avanzado y eficiente del DOM, gestión de estado local y persistencia de datos en el navegador. Es una solución ideal para arquitecturas ligeras que requieren alto rendimiento y tiempos de carga mínimos.

---

## 🚀 Funcionalidades Principales (Features)

*   **Catálogo Dinámico:** Renderizado de productos a partir de estructuras de datos (Arrays de Objetos) generadas dinámicamente mediante JavaScript.
*   **Búsqueda en Tiempo Real:** Motor de filtrado instantáneo que reacciona a la entrada del usuario en la barra de búsqueda, actualizando el DOM sin recargar la página.
*   **Ordenamiento de Datos:** Botones de acción para ordenar el catálogo alfabéticamente (por nombre) o numéricamente (precio de menor a mayor).
*   **Gestión Completa del Carrito:** 
    *   Agregar y eliminar productos individualmente.
    *   Cálculo dinámico del precio total y contador de ítems en el header.
    *   Botón de vaciado total (Clear Cart).
*   **Persistencia de Datos:** Integración con `localStorage` del navegador. El estado del carrito (productos, totales y cantidades) se guarda automáticamente y se recupera al recargar la sesión, garantizando una excelente experiencia de usuario (UX).

---

## 🛠️ Tecnologías Utilizadas

*   **Lenguaje:** JavaScript ES6+ (Vanilla JS).
*   **Estructura y Estilos:** HTML5 semántico y CSS3 con diseño responsivo.
*   **Almacenamiento:** Web Storage API (`localStorage`).
